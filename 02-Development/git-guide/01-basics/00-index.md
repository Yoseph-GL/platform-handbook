# Git Level 1: Basics

## Architecture / Rationale

This level covers the fundamental Git commands you use every day. You learn to track changes, view history, work with branches, and fix mistakes.

Scope:
- What Git is and how to set it up.
- Making commits and viewing changes.
- Undoing mistakes and modifying history.
- Branching and merging.
- Ignoring files and creating shortcuts.

## Performance / Optimization Notes

- Learn the basic workflow first: edit, stage, commit, repeat. Everything else builds on this.
- Branches are cheap in Git. Create a new branch for every feature or experiment.
