# Git GitHub: Next Steps

## Architecture / Rationale

You now have the foundation for using Git and GitHub effectively. This note suggests what to learn next and how to keep improving.

Where to go from here:
- Practice every day. The commands become automatic with repetition.
- Contribute to an open-source project. Start with documentation fixes, then move to code.
- Learn more advanced Git features as you need them. Do not try to learn everything at once.

## Query / Code Blocks

```bash
# Keep practicing the daily workflow:
git status
git add <files>
git commit -m "message"
git push

# Explore a real open-source project
git clone https://github.com/freeCodeCamp/freeCodeCamp.git

# Learn to read the Git history
git log --oneline --graph --decorate
```

## Performance / Optimization Notes

- The best way to learn Git is to use it. Create a small project and track it with Git from day one.
- Read other people's commit messages to see how experienced developers write them.
- When you make a mistake, do not panic. Git almost always has a way to recover your work.
