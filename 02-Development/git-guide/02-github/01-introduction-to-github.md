# Git GitHub: Introduction to GitHub

## Architecture / Rationale

GitHub is a platform that hosts Git repositories online. It adds collaboration tools like pull requests, issues, and project boards on top of Git.

Key facts:
- GitHub is not Git. Git is the version control system. GitHub is a service that hosts Git repositories.
- GitHub is the largest host of open-source code in the world.
- Alternatives exist (GitLab, Bitbucket) but GitHub is the most widely used.

## Query / Code Blocks

```bash
# You interact with GitHub through Git commands and the web interface
# Git commands: clone, push, pull, fetch
# Web interface: create repos, pull requests, issues, settings
```

## Performance / Optimization Notes

- Create a GitHub account with the same email you use in your Git configuration.
- Your GitHub profile is your developer resume. Keep your repositories and contributions organized.
- Public repositories are visible to everyone. Private repositories are only visible to you and people you invite.
