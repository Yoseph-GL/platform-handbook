# Bash Setup: Warp Terminal

## Architecture / Rationale

Warp is a modern terminal application built for developers. It adds features like command autocompletion, AI assistance, and a notebook-style output to the traditional terminal experience.

Key features:
- Block-based output: each command and its output are grouped visually.
- AI command suggestions: describe what you want in plain English.
- Works with Bash, Zsh, and Fish.

## Query / Code Blocks

```bash
# Warp runs your default shell (Bash or Zsh)
# All commands work the same as in any other terminal
echo "Hello from Warp"
```

## Performance / Optimization Notes

- Warp is a terminal, not a shell. It does not change how your commands work.
- If you are learning Bash, Warp's suggestions can help you discover new commands.
- Warp is available on macOS and Linux. It is not yet available on Windows.
