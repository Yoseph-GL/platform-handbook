# Bash Level 3: File Management

## Architecture / Rationale

This level covers how Unix organizes files and how you work with them. You learn the file system structure, file operations, and pattern matching.

Scope:
- The Unix file system layout and hierarchy.
- Creating, copying, moving, and deleting files and folders.
- Wildcards for matching multiple files at once.
- Advanced listing with `ls` flags.
- Identifying file types with the `file` command.

## Performance / Optimization Notes

- Understanding the file system structure helps you find files faster.
- Wildcards save time. One command can apply to dozens of files instead of typing each name.
