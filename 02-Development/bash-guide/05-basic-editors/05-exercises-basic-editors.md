# Bash Basic Editors: Exercises

## Architecture / Rationale

These exercises build muscle memory with terminal editors. Practice with both Nano and Vim so you can use either when needed.

## Query / Code Blocks

```bash
# Exercise 1: Open Nano and type a short paragraph about what you learned today.
# Exercise 2: Save the file as "today.txt" and exit Nano.
# Exercise 3: Open the same file in Nano. Use Ctrl+W to search for a word.
# Exercise 4: Use Ctrl+\ to replace one word with another. Save and exit.
# Exercise 5: Open Vim and type a list of your 5 favorite commands so far.
# Exercise 6: Save the file as "commands.txt" and exit Vim (:wq).
# Exercise 7: Open commands.txt in Vim. Navigate with h, j, k, l (left, down, up, right).
# Exercise 8: In Vim, copy a line with yy and paste it with p.
# Exercise 9: In Vim, delete a line with dd, then undo with u.
# Exercise 10: Run `vimtutor` and complete at least the first 3 lessons.
```

## Performance / Optimization Notes

- Spend at least 15 minutes on exercise 10. `vimtutor` is the fastest way to learn Vim basics.
- If you get stuck in Vim, press `Esc` several times, then type `:q!` to exit.
- The goal is not speed. The goal is knowing you can edit a file on any server you connect to.
