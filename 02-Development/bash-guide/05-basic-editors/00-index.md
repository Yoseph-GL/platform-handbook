# Bash Level 5: Basic Editors

## Architecture / Rationale

Terminal text editors let you edit files without leaving the terminal. Every developer needs to know at least one terminal editor for remote work and quick edits.

Scope:
- Overview of terminal editors and when to use each.
- Nano: the simplest editor for beginners.
- Vim: the powerful modal editor.
- Other editors: Neovim and Emacs.

## Performance / Optimization Notes

- Learn one editor well. Nano is easier to start with. Vim is more powerful in the long run.
- Every server has Nano or Vim installed. Knowing at least one means you can edit files anywhere.
