# Bash First Steps: Exercises

## Architecture / Rationale

Practice is the only way to learn Bash. These exercises use only the commands from the First Steps module.

Do each exercise in your terminal. Write down the command you used and what happened.

## Query / Code Blocks

```bash
# Exercise 1: Print "I am learning Bash" to the terminal.
# Exercise 2: Show your current working directory.
# Exercise 3: List all files in your home folder.
# Exercise 4: Create a folder called "practice" in your home folder.
# Exercise 5: Move into the "practice" folder using a relative path.
# Exercise 6: Create an empty file called "test.txt".
# Exercise 7: Go back to your home folder using two different methods.
# Exercise 8: Copy "test.txt" to "test-backup.txt".
# Exercise 9: Rename "test-backup.txt" to "backup.txt".
# Exercise 10: Find the full path of the `ls` command using `which`.
# Exercise 11: Check if `cd` is a built-in or a program using `type`.
# Exercise 12: Read the manual page for `mkdir` and find the option to create parent folders.
```

## Performance / Optimization Notes

- Complete every exercise before moving to the next module.
- If you get stuck, use `man` or `--help` to find the answer before searching online.
- Type every command yourself. Copying and pasting does not build muscle memory.
