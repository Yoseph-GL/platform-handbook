# Bash Level 8: Scripting

## Architecture / Rationale

Shell scripts automate sequences of commands. Instead of typing the same commands every day, you write them once in a file and run that file.

Scope:
- Writing and running your first script.
- Reading user input with `read`.
- Printing output with `echo` and `printf`.
- Passing arguments to scripts.

## Performance / Optimization Notes

- Scripts save time and prevent mistakes. If you run the same 5 commands every day, put them in a script.
- Always start scripts with `#!/bin/bash` (the shebang). It tells the system which shell to use.
