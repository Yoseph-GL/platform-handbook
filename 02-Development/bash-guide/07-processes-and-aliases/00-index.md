# Bash Level 7: Processes and Aliases

## Architecture / Rationale

This level covers how to manage running programs and how to create shortcuts for commands you use often.

Scope:
- Listing and managing processes.
- Running and controlling background jobs.
- Reusing previous commands with history.
- Creating aliases for long or complex commands.
- Pausing and waiting with `sleep` and `wait`.

## Performance / Optimization Notes

- Aliases save keystrokes. If you type a command more than five times a day, make an alias for it.
- Understanding processes helps you find and stop programs that are using too many resources.
