# HTML/CSS Guide Index

## Architecture / Rationale

This guide is a structured learning path for HTML and CSS. It goes from basic web concepts to advanced CSS techniques.

Level boundaries:
0. **Level 0 - Introduction:** what the web is, how HTML and CSS work, and the tools you need.
1. **Level 1 - Basic HTML:** tags, page structure, text, lists, links, images, and forms.
2. **Level 2 - Basic CSS:** selectors, fonts, box model, spacing, borders, colors, and units.
3. **Level 3 - Advanced HTML:** forms advanced, tables, media, semantic tags, and accessibility.
4. **Level 4 - Intermediate CSS:** specificity, pseudo-classes, BEM, display, positioning, and transitions.
5. **Level 5 - CSS Flexbox:** one-dimensional layout with flex containers and items.
6. **Level 6 - Responsive Design:** flexible media, media queries, mobile-first, and container queries.
7. **Level 7 - CSS Grid:** two-dimensional layout with grid templates, areas, and subgrid.
8. **Level 8 - Animations:** transitions, keyframes, scroll-based effects, and integration.
9. **Level 9 - Web Hosting:** deploying your site to the internet.
10. **Level 10 - Advanced CSS:** filters, transforms, custom properties, calc, and modern functions.

Current implementation scope is Level 0 through Level 10.
