# HTML/CSS Level 5: CSS Flexbox

## Architecture / Rationale

Flexbox is a one-dimensional layout system. It arranges items in a row or a column and distributes space between them. It is the standard way to build navigation bars, card grids, and centered content.

Scope:
- Flex containers and flex items.
- Direction, wrapping, and flow.
- Alignment on the main and cross axes.
- Item order, sizing with flex-basis, grow, and shrink.
- Align-self for individual items.
- Real-world layout patterns.

## Performance / Optimization Notes

- Flexbox is faster than float-based layouts and easier to maintain.
- Use Flexbox for one-dimensional layouts (rows OR columns). Use Grid for two-dimensional layouts.
- Flexbox is supported in all modern browsers, including IE11 with minor issues.
