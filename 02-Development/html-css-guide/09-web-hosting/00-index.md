# HTML/CSS Level 9: Web Hosting

## Architecture / Rationale

A website needs to be on the internet for other people to see it. Web hosting makes your files publicly accessible. This level covers the basics of deploying a site.

Scope:
- What web hosting is and the types available.
- How to upload your HTML and CSS files to a server.

## Performance / Optimization Notes

- A good hosting provider handles SSL certificates, backups, and uptime monitoring for you.
- Your first site can be hosted for free on services like GitHub Pages or Netlify.
- Always test your site on the live URL after uploading. Cached files from local development can hide problems.
