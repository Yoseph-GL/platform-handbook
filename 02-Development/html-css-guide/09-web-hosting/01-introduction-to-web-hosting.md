# Web Hosting: Introduction to WEB HOSTING

## Architecture / Rationale

Web hosting is a service that stores your website files and serves them to visitors. When someone types your domain name, the hosting server sends back your HTML, CSS, and other files.

Types of hosting:
- **Shared hosting**: many sites on one server. Cheap, good for small sites.
- **VPS (Virtual Private Server)**: a virtual machine just for you. More control.
- **Static hosting**: for sites with only HTML, CSS, and JavaScript. Free options exist (GitHub Pages, Netlify).
- **Cloud hosting**: scalable servers on platforms like AWS or Vercel.

## Performance / Optimization Notes

- Static hosting is the fastest and cheapest option for HTML/CSS-only sites. Start there.
- Your domain name (like `mysite.com`) is separate from your hosting. You buy a domain from a registrar and point it to your host.
- Always enable HTTPS. Most modern hosting services offer it for free.
