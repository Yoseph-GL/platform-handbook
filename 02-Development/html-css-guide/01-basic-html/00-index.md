# HTML/CSS Level 1: Basic HTML

## Architecture / Rationale

This level covers the building blocks of every web page. You learn the tags that give a page its structure and content.

Scope:
- HTML tag anatomy and attributes.
- Page boilerplate (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`).
- Text elements: paragraphs, headings, and lists.
- Links and images with paths.
- Basic forms for user input.

## Performance / Optimization Notes

- Write valid HTML from the start. The browser forgives mistakes, but clean code is easier to debug.
- Use heading levels in order (`h1` → `h2` → `h3`). Do not skip levels.
- Keep this level as the minimum standard before adding CSS or JavaScript.
