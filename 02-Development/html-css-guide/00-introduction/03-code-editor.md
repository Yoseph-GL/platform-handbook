# Web Foundations: Code Editor

## Architecture / Rationale

A code editor is the tool you use to write HTML and CSS files. It checks your syntax, suggests completions, and helps you work faster.

Key facts:
- A code editor is not the same as a word processor (like Word). It saves plain text, not formatted documents.
- Popular free editors: Visual Studio Code, Sublime Text, and alternatives.
- Your editor should highlight HTML tags and CSS properties in different colors (syntax highlighting).

## Performance / Optimization Notes

- Install an HTML/CSS extension in your editor for autocompletion and error checking.
- Use a dark theme to reduce eye strain during long coding sessions.
- Learn your editor's keyboard shortcuts. They save hours over the course of a project.
