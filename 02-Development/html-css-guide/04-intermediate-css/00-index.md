# HTML/CSS Level 4: Intermediate CSS

## Architecture / Rationale

This level deepens your CSS skills. You learn how the cascade and specificity work, how to use advanced selectors, and how to control layout with positioning and display.

Scope:
- Advanced selectors (attribute, combinator).
- Inheritance, cascade, and specificity.
- Pseudo-classes and pseudo-elements.
- BEM methodology for naming classes.
- Display modes and positioning schemes.
- Transitions, overflow, and text flow.
- Object-fit and Emmet shortcuts.

## Performance / Optimization Notes

- Understanding specificity is critical. Most CSS bugs come from conflicting selectors.
- BEM keeps class names predictable in large projects.
- Use transitions sparingly on low-end mobile devices.
