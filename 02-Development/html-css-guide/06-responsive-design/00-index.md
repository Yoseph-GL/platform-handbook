# HTML/CSS Level 6: Responsive Design

## Architecture / Rationale

Responsive design makes your site work on all screen sizes. It combines flexible layouts, responsive images, and media queries to adapt the design to the device.

Scope:
- Flexible blocks and multimedia.
- Responsive images with `srcset`, `sizes`, and `<picture>`.
- Media queries and breakpoints.
- Mobile-first design strategy.
- Feature queries and container queries.

## Performance / Optimization Notes

- Test on real devices. Emulators catch layout bugs but not performance issues or touch behavior.
- Responsive design is not optional. Over 60% of web traffic comes from mobile devices.
- Build mobile-first. It forces you to focus on what really matters.
