# HTML/CSS Level 2: Basic CSS

## Architecture / Rationale

This level covers the fundamentals of CSS styling. You learn how to select elements and apply visual properties.

Scope:
- How CSS connects to HTML (inline, internal, external).
- Basic selectors (element, class, ID).
- Text and font styling.
- The box model, padding, margin, and borders.
- Colors, units, and backgrounds.

## Performance / Optimization Notes

- Use an external CSS file linked in the `<head>`. It keeps HTML clean and lets the browser cache the styles.
- Start with simple selectors. Avoid over-qualifying them until you understand specificity.
- Build the habit of checking your styles in multiple browsers early.
