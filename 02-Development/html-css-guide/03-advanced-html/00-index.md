# HTML/CSS Level 3: Advanced HTML

## Architecture / Rationale

This level covers more HTML elements that make your pages richer and more accessible. It includes advanced form controls, tables, media elements, and semantic structure.

Scope:
- Metatags, comments, and favicons.
- Advanced form controls (textarea, select, fieldset, datalist).
- Interactive elements (details/summary).
- Tables, audio, video, and lazy loading.
- Semantic HTML and web accessibility.
- Deprecated tags to avoid.

## Performance / Optimization Notes

- Semantic HTML is not just for looks — it helps search engines and screen readers understand your content.
- Always provide fallback content for audio and video elements.
- Deprecated tags still work but should never be used in new projects.
